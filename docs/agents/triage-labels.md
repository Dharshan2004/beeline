# Triage Labels

The engineering skills use five canonical triage roles. Their names map directly to labels in this repository's GitHub issue tracker.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for information from its reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill mentions a triage role, use the corresponding GitHub label from this table.
