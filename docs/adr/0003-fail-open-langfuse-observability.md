# Keep Langfuse observability outside the scoring path

The Shopping Agent will emit Langfuse traces during normal development and connected runtime operation, grouping turn traces by evaluation session and nesting interpretation, retrieval, fusion, clarification, reranking, and fallback observations. Traces record structured decisions, confidence, reason codes, candidate counts, timings, model usage, configuration identity, and failure causes, but never request or store private chain-of-thought, credentials, full catalog records, or the raw user profile. Observability is strictly fail-open: missing credentials, export delays, client errors, or lost network access disable trace delivery without changing recommendations, response validity, or latency-critical control flow. This preserves useful operational evidence without making official scoring depend on an external service whose network availability is not guaranteed.
