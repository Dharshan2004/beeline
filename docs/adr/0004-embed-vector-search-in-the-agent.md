# Embed vector search in the agent process

Dense retrieval will use Qdrant Local Mode inside the Shopping Agent process, backed by a versioned local index and requiring no network connection, listening port, or separately managed service. The same agent remains LLM-centered: the LLM interprets turns, proposes Constraint State changes, chooses tools and clarifications, and may rerank and compose responses; embedded Qdrant is only the implementation of the dense Retrieval Route that the loop can invoke. A single Docker image will package the agent, local retrieval dependencies, selected models, and indexes for reproducible development and demonstration, while the official Python Agent entry point will also run directly without Docker. A separately hosted Qdrant instance may be offered as an optional development profile, but scoring and correctness must never depend on it being available.
